What the Elevator Would Say: a tiny Python program (stdlib only, no network) that writes the funniest one line a talking elevator could say to `/output/entry.txt` — a tired elevator, fed up with passengers mashing the close-door button.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
